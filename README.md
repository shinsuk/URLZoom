# URLZoom

크롬 브라우저의 기본 도메인 단위 줌(Zoom) 기억 방식을 우회하여, **개별 전체 URL(Full URL) 단위로 독립적인 확대/축소 비율을 고정하고 관리**할 수 있는 크롬 확장 프로그램입니다.

## 🌟 주요 기능

- **정밀한 URL 기반 줌 제어**: `example.com` 도메인 전체가 아니라 `example.com/page1`과 `example.com/page2`의 줌 비율을 다르게 설정할 수 있습니다.
- **독립적 격리 보장**: 탭(Tab) 기반 줌 설정을 통해, 같은 도메인 내의 다른 페이지로 이동하더라도 서로의 줌 설정에 영향을 주지 않습니다.
- **편리한 팝업 UI**: 현재 페이지의 줌 설정을 한 번의 클릭으로 저장하고, 적용된 비율을 바로 확인할 수 있습니다.
- **스마트한 기본값**: 새로운 페이지에서 팝업을 열면, 브라우저에 현재 적용된 줌 비율을 기본값으로 가져옵니다.
- **설정 관리 페이지 (Options)**: 저장된 전체 URL 목록을 확인하고, 웹 페이지 제목(Title), URL, 줌 비율을 직접 텍스트 박스로 편집하거나 정렬(Sort)할 수 있습니다.
- **보안 예외 처리**: 크롬 시스템 페이지(`chrome://`, `edge://` 등)에서는 안전하게 비활성화되어 오류를 방지합니다.

## 🚀 설치 방법

1. 소스 코드를 로컬 환경에 다운로드합니다.
2. 크롬 브라우저에서 `chrome://extensions/` 페이지로 이동합니다.
3. 우측 상단의 **"개발자 모드"**를 켭니다.
4. **"압축해제된 확장 프로그램을 로드합니다"** 버튼을 클릭하고, 소스 코드가 있는 폴더(`URLZoom`)를 선택합니다.
5. 브라우저 우측 상단 퍼즐 아이콘을 눌러 "URLZoom"을 고정(Pin)합니다.

## 🛠 사용 방법

1. 줌 비율을 고정하고 싶은 페이지에 접속합니다.
2. 우측 상단의 확장 프로그램 아이콘을 클릭합니다.
3. 원하는 줌 비율(%)을 입력하고 **"이 URL에 저장"** 버튼을 클릭합니다.
4. 이후 해당 주소에 접속할 때마다 설정한 줌 비율이 자동으로 유지됩니다.
5. 저장된 목록을 확인하거나 직접 편집하려면 팝업 하단의 **"저장 목록 관리"** 버튼을 누르거나 확장 프로그램 설정에서 '확장 프로그램 옵션'에 진입합니다.

- **v1.7.0**: 설정 페이지 테이블 헤더 클릭 시 오름차순/내림차순 정렬 방향 시각화 (↑, ↓) 추가
- **v1.6.0**: 설정 페이지에서 제목, URL, 줌 비율 기준 오름차순/내림차순 정렬 기능 추가

- **v1.4.0**: 설정 페이지 목록 관리 화면에서 제목(Title)과 URL을 직접 텍스트 박스로 수정할 수 있도록 UI/UX 고도화
- **v1.3.0**: 줌 설정 저장 시 웹 페이지의 제목(Title)을 함께 저장 및 옵션 페이지에 표시하여 가독성 증대
- **v1.2.0**: 도메인 간 줌 설정 간섭 방지를 위해 `per-tab` 격리 적용 및 `requirements.md` 문서화
- **v1.1.1**: `chrome://`, `edge://`, `about:` 등 보안 URL 접근 시 발생하는 Promise 에러 처리 및 팝업 UI 피드백 추가
- **v1.1.0**: 저장된 URL을 한눈에 보고 삭제할 수 있는 옵션(Options) 페이지 추가
- **v1.0.0**: 팝업을 통한 URL 줌 저장 및 백그라운드를 통한 자동 복구의 핵심 뼈대 구현
